# Start

You need Node.js 18+ and a running PostgreSQL server.

# 1. Backend (Steps To Run The Backend)

```bash
cd backend
npm install
cp .env
npm start
```
Open `.env` and put in your own PostgreSQL password (and change the other values if needed). Then start the server:
